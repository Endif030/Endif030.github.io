## 🎯 选入标准与算法

### 综合排序算法

论文按照以下多维权重综合排序选入：

```
综合得分 = 时间权重 × 40% + 引用影响力 × 30% + 学科匹配度 × 30%
```

#### 1. 时间权重 (40%)
| 发表时间 | 权重系数 |
|---------|---------|
| 2026年 | 1.0 |
| 2025年 | 0.9 |
| 2024年 | 0.7 |
| 2023年 | 0.5 |
| 2022年及以前 | 0.3 |

**理由**: 优先追踪最新研究进展，确保知识的时效性

#### 2. 引用影响力 (30%)
| 引用次数 | 权重等级 |
|---------|---------|
| 1000+ | A级 (最高) |
| 500-999 | B级 |
| 100-499 | C级 |
| 10-99 | D级 |
| <10 | E级 |

**理由**: 引用数是学术界公认的影响力指标，高引用论文通常代表重要突破或经典方法

#### 3. 学科匹配度 (30%)
- **arXiv**: 按精确分类代码匹配（如cs.AI匹配人工智能）
- **Semantic Scholar**: 按关键词和领域标签匹配

**理由**: 确保论文与学科高度相关，避免"噪音"论文
