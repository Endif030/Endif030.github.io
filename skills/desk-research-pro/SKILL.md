# 桌面研究专家 (Desk Research Pro)

专业桌面研究助手，参照毕马威、艾瑞咨询、灼识咨询、国金证券等专业机构研报质量标准，帮助用户高效完成从资料收集到报告输出的完整研究流程。

## 质量标准参照

本Skill输出标准基于以下6份专业研报提炼：
- 毕马威《2023/2025中国金融科技企业双50报告》
- 灼识咨询《大模型与AIGC蓝皮书》
- 艾瑞咨询《中国办公信创/金融信创研究报告》
- 国金证券《金融路演PPT生成框架研究》

---

## 适用场景

- 行业市场调研（参照咨询机构标准）
- 投资分析/投行研报
- 竞品分析报告
- 政策文件梳理
- 趋势分析报告
- 商业计划书资料支撑

## 工作流程

### Phase 1: 需求确认与框架设计

**第一步：确认研究需求**
- 明确报告主题、目标受众、使用场景
- 确定研究范围和边界（中国/全球/细分市场）
- 识别核心问题和关键指标
- 确认交付物形式（完整报告/PPT/数据表）
- **明确质量要求**：是否需达到投研/咨询级标准

**第二步：设计研究框架**
- 拟定详细的研究维度（参照专业报告结构）
- 设计数据收集清单
- 规划报告结构（执行摘要→现状→细分→案例→趋势）
- 识别潜在数据来源（一手访谈+二手报告+公开资料）

**输出**: 研究计划文档，包含框架、步骤、预期输出、数据来源

**注意**: 必须获得用户确认后再进入下一步

---

### Phase 2: 资料收集与整理

**第三步：桌面资料检索**
- 使用 Tavily API 进行多维度搜索
- 收集行业报告、新闻、数据、案例
- **区分信息来源**：专家访谈（私有）vs 公开报告/新闻（公有）
- 保存原始资料到结构化文件

**搜索策略**:
```python
# 多维度搜索模板
queries = [
    "{主题} 市场规模 2024 行业报告",
    "{主题} 发展趋势 用户画像",
    "{主题} 竞争格局 主要玩家",
    "{主题} 商业模式 营收结构",
    "{主题} 政策法规 行业标准",
    "{主题} 标杆案例 {行业龙头}"
]
```

**第四步：资料分类与摘要**
- 按研究维度分类资料
- 提取关键数据和信息
- **标注数据来源和发布时间**
- 识别数据缺口，制定补充搜索计划

**输出**: 
- 原始资料库 (JSON格式)
- 分类摘要文档
- 数据缺口清单

---

### Phase 3: 分析与报告撰写

**第五步：数据分析**
- 对比不同来源数据，交叉验证
- 识别趋势和规律
- 估算缺失数据（明确标注⚠️）
- **整理标杆案例**（企业名称、模型/产品、核心数据）

**第六步：报告撰写**

**完整报告结构**（参照咨询机构标准）：
1. 执行摘要（核心发现3-4条，一页纸原则）
2. 研究背景与方法论
3. 行业/市场发展历程
4. 市场现状分析（规模、增速、结构）
5. 细分领域深度解析
6. 标杆案例研究（3-5个典型案例）
7. 竞争格局分析
8. 产业链分析
9. 前景与机会
10. 风险提示
11. 数据来源与附录

**第七步：数据可视化**
- 使用 python-pptx 创建专业图表
- 图表类型选择：
  - 时间趋势 → 折线图
  - 类别对比 → 柱状图
  - 占比构成 → 饼图/环形图
  - 排名对比 → 条形图
- **必须标注**：图表标题+数据来源+单位

## 输出质量标准

### 视觉设计标准

**配色方案**（金融/咨询类）：
| 用途 | 颜色 | RGB |
|------|------|-----|
| 主色调 | 深海蓝 | (0, 51, 102) |
| 辅助色 | 科技蓝 | (0, 112, 192) |
| 强调色 | 活力橙 | (255, 127, 39) |
| 正文字 | 深灰 | (64, 64, 64) |
| 次要信息 | 浅灰 | (128, 128, 128) |

**字体规范**：
- 标题：思源黑体/微软雅黑，20-32pt，Bold
- 正文：思源黑体/微软雅黑，10-14pt，Regular
- 图表标注：9-10pt
- 数据来源：8-9pt，浅灰色，右对齐

**布局标准**：
- 页边距 ≥ 1.5cm
- 内容占页面 ≤ 60%
- 每页PPT正文 ≤ 150字
- 使用bullet point呈现要点

### 内容质量标准

**数据来源标注**（必须）：
- 每条数据必须注明来源
- PPT图表底部用小字标注："数据来源：XXX"
- 区分：专家访谈资料（标注受访者/时间）vs 公开资料

**示例**:
```
数据来源：毕马威2024中国金融科技企业首席洞察报告
私有资料：科大讯飞专家访谈，2023年11月
```

**数据缺口处理**：
- 使用 ⚠️ 符号标记缺失数据
- 说明缺失原因
- 提供获取建议

**内容密度控制**：
- 结论先行，数据支撑
- 每页1个核心观点
- 使用对比分析（vs、从...到...）

### PPT结构标准

**标准页数**：12-15页

**必含页面**：
1. 封面（简洁大气，机构VI色系）
2. 目录（6个章节左右）
3. 研究背景与方法论
4. 市场规模（核心数据卡片）
5. 应用场景/细分分析
6. 标杆案例（3-4个）
7. 竞争格局/对比分析
8. 发展趋势
9. 核心结论
10. 免责声明（投研报告必需）

## 投研报告特殊要求

如用户要求投研级质量，需额外满足：

1. **内容重于形式**：避免花哨设计，突出专业性和数据准确性
2. **图表可溯源**：所有图表可追溯到原始数据来源
3. **免责声明**：包含投资风险提示
4. **时效性**：标注数据截止日期
5. **一致性**：统一术语、格式、配色

## 执行指令

当用户触发此 skill 时：

1. **阅读 references/ppt-quality-standards.md** 获取完整质量标准
2. **询问用户研究需求**（主题、范围、质量要求、交付物）
3. **制定研究计划** 并获取确认
4. **执行资料收集** 使用 Tavily API，区分私有/公有来源
5. **整理分析资料** 按维度分类，标注来源
6. **撰写报告** 参照 report-template.md
7. **生成PPT** 使用 scripts/generate_ppt.py，符合质量标准
8. **自检** 对照质量标准checklist
9. **交付成果** 完整报告 + PPT + 资料库

## 自检Checklist

交付前必须检查：

**视觉设计** ✓
- [ ] 配色符合专业标准（深蓝+科技蓝+橙色）
- [ ] 字体统一（微软雅黑/思源黑体）
- [ ] 留白充足，不拥挤
- [ ] 页眉页脚规范

**内容组织** ✓
- [ ] 目录层级清晰（6章左右）
- [ ] 结论先行，数据支撑
- [ ] 术语使用规范
- [ ] 章节过渡自然

**图表质量** ✓
- [ ] 图表类型选择恰当
- [ ] 数据标注完整（标题+来源+单位）
- [ ] 表格设计规范（深色表头+斑马纹）

**文字表达** ✓
- [ ] 标题简洁有力（≤15字）
- [ ] 正文精炼准确（每页≤150字）
- [ ] 引用规范标注
- [ ] 无错别字

**数据来源** ✓
- [ ] 每条数据标注来源
- [ ] 区分私有/公有资料
- [ ] 数据时效性说明
- [ ] ⚠️标注缺失数据
