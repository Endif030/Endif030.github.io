# PPT质量标准手册

## 基于专业研报（毕马威/艾瑞/灼识/国金证券）的质量标准

---

## 一、整体视觉设计标准

### 1.1 配色体系

**金融/咨询类报告标准配色：**

| 用途 | 颜色名称 | RGB值 | 使用场景 |
|------|---------|-------|----------|
| 主色调 | 深海蓝 | (0, 51, 102) | 标题、重点强调、章节页 |
| 辅助色 | 科技蓝 | (0, 112, 192) | 图表、中国数据系列 |
| 强调色 | 活力橙 | (255, 127, 39) | 高亮、增长指标、美国数据 |
| 正文字 | 深灰 | (64, 64, 64) | 正文文字 |
| 次要信息 | 中灰 | (128, 128, 128) | 来源标注、辅助说明 |
| 背景色 | 白色/浅灰 | (250, 250, 250) | 页面背景 |
| 成功/正向 | 绿色 | (0, 176, 80) | 正向指标、增长 |

**科技/信创类报告配色：**
- 可使用渐变色彩或科技感色系
- 强调色可用紫色（代表AI/大模型）
- 保持整体协调统一

### 1.2 字体规范

| 用途 | 字体 | 字号 | 字重 | 颜色 |
|------|------|------|------|------|
| 报告大标题 | 思源黑体/微软雅黑 | 36-44pt | Bold | 深海蓝 |
| 章节标题 | 思源黑体/微软雅黑 | 20-28pt | Bold | 深海蓝 |
| 页面小标题 | 思源黑体/微软雅黑 | 16-20pt | Bold | 深海蓝 |
| 正文 | 思源黑体/微软雅黑 | 12-14pt | Regular | 深灰 |
| 图表标注 | 思源黑体/微软雅黑 | 10-11pt | Regular | 深灰 |
| 数据来源 | 思源黑体/微软雅黑 | 8-9pt | Regular | 浅灰 |
| 页码 | 思源黑体/微软雅黑 | 10pt | Regular | 浅灰 |

### 1.3 页面布局标准

**标准内容页 = 页眉 + 标题区 + 内容区 + 数据来源 + 页脚**

**边距规范：**
- 页面边距：≥1.5cm
- 元素间距：≥0.5cm
- 段落间距：1.2-1.5倍行距
- 图表与文字间距：≥0.8cm

**内容密度：**
- 每页PPT正文不超过150字
- 每段文字3-5行为宜
- 使用 bullet point 呈现要点

## 二、页面类型标准

### 2.1 封面设计

**布局要求：**
- 简洁大气，标题占比不超过页面40%
- 左侧/居中放置主标题
- 右下角或底部放置机构信息
- 大量留白

**必含元素：**
1. 报告主标题（年度+主题）
2. 副标题（报告性质）
3. 发布日期
4. 机构名称/Logo位置

### 2.2 目录页

**结构：**
- 6个章节左右为宜
- 编号清晰（01、02、03...）
- 可加英文对照（如 Hybrid Working）

**示例：**
```
01  研究背景与方法论
02  金融行业大模型应用现状
03  传媒行业大模型应用现状
04  标杆案例深度解析
05  市场格局与竞争态势
06  发展趋势与展望
```

### 2.3 章节过渡页

**设计要求：**
- 大号章节编号（60-80pt）
- 中英双语章节名
- 可使用相关意象图片（低透明度）
- 底部加装饰线条

### 2.4 内容页

**标准结构：**
1. **页眉**（可选）：报告名称或章节名，左对齐，小字号
2. **标题区**：页面主题，16-20pt，加粗
3. **内容区**：正文/图表/表格，灵活布局
4. **数据来源**：页面底部，右对齐，浅灰色
5. **页码**：右下角

## 三、图表与数据可视化标准

### 3.1 图表类型选择

| 数据类型 | 推荐图表 | 示例场景 |
|----------|----------|----------|
| 时间序列/趋势 | 折线图 | 市场规模增长、趋势演变 |
| 类别对比 | 柱状图 | 企业排名、地区分布 |
| 占比构成 | 饼图/环形图 | 市场份额、收入结构 |
| 排名对比 | 条形图（横向） | TOP10榜单 |
| 流程/阶段 | 流程图 | 发展阶段、落地流程 |
| 对比关系 | 表格 | 企业名单、功能对比 |
| 架构/层级 | 结构图 | 产业链、体系架构 |

### 3.2 数据卡片设计

**核心数据展示（市场规模页）：**
- 使用圆角矩形卡片
- 卡片底色根据数据类型选择（蓝/橙/绿）
- 大号数字显示（26-32pt）
- 白色文字，居中显示
- 下方小字标注说明

**示例布局：**
```
┌─────────────┐  ┌─────────────┐  ┌─────────────┐
│  26.46亿元   │  │    140%+    │  │  310亿元    │
│ 2024年规模   │  │  2024增长率  │  │ 2029年预测  │
└─────────────┘  └─────────────┘  └─────────────┘
     深蓝底色         科技蓝底色        活力橙底色
```

### 3.3 表格设计标准

**基础规范：**
- 表头：深色背景（深蓝/深灰）+ 白色文字
- 内容行：斑马纹（奇数行浅灰，偶数行白色）
- 边框：仅保留横向细线，纵向无边框
- 对齐：文字左对齐，数字右对齐，表头居中
- 行高：1.5倍行距

**示例：**
```
┌──────────┬──────────┬────────────────┐
│ 企业简称 │ 市场份额 │    核心优势    │  ← 深蓝底色+白字
├──────────┼──────────┼────────────────┤
│ 企业A    │   25%    │ 技术领先       │  ← 浅灰底
│ 企业B    │   20%    │ 渠道优势       │  ← 白色底
│ 企业C    │   15%    │ 品牌影响力     │  ← 浅灰底
└──────────┴──────────┴────────────────┘
```

### 3.4 数据标注规范

**必须包含的元素：**

1. **图表标题**
   - 置于图表上方或左侧
   - 清晰说明图表内容
   - 格式："图表X：XXX"

2. **数据来源**
   - 标注于图表下方右侧
   - 格式："数据来源：XXX"
   - 字号：8-9pt，浅灰色

3. **单位标注**
   - 明确数值单位（亿元、万美元、百分比等）
   - 在图表或坐标轴标注

4. **时间标注**
   - 数据截止时间或统计周期
   - 预测数据标注"预测"字样

**示例：**
```
图表1：中国金融科技市场规模及增速
[柱状图+折线图]

数据来源：艾瑞咨询，2023年
```

## 四、内容组织标准

### 4.1 标题撰写规范

| 层级 | 字数限制 | 示例 |
|------|----------|------|
| 章节标题 | ≤15字 | "大模型的发展现状与趋势展望" |
| 页面标题 | ≤12字 | "信创实践应用的挑战分析" |
| 图表标题 | ≤15字 | "2023年金融科技企业融资规模" |

### 4.2 正文撰写标准

**表达原则：**
- **结论先行**：先给出观点，再解释原因
- **数据支撑**：关键结论必须配数据
- **对比分析**：多用"相较于"、"从...到..."

**Bullet Point规范：**
- 使用"•"作为项目符号
- 每点一个完整句子或短语
- 保持语法平行（都是短语或都是句子）

**示例（艾瑞咨询风格）：**
```
办公应用属于信创体系顶层，需具备国产独立标准+信创环境兼容的特点
• 从信创体系看：办公软件属于应用软件中通用软件部分
• 从企业应用看：相对于财务、研发等业务系统，仍处在边缘软件范畴
```

### 4.3 专业术语使用

**规范性要求：**
- 首次出现缩写需标注全称
  - 例：AIGC（AI Generated Content）
- 统一术语表述
  - 不使用"大模型"和"大型模型"混用
- 英文术语大小写统一
  - 例：ChatGPT、GPT-4

### 4.4 引用与注释

**国金证券研报标准：**
- 图表下方标注"来源：XXX"
- 关键数据标注"截至202X年X月"
- 预测性数据标注"预测"字样
- 专家访谈资料标注受访者/时间

## 五、标杆案例呈现标准

### 5.1 案例卡片设计

**布局：**
- 使用圆角矩形卡片
- 浅灰背景+深色边框
- 卡片内包含：企业名、产品/模型名、核心数据/亮点

**必含信息：**
1. 企业名称（加粗，品牌色）
2. 大模型/产品名称
3. 3-4条核心数据或亮点
4. 数据标注来源

**示例：**
```
┌─────────────────────────────────────┐
│ 工商银行                            │ ← 深海蓝，14pt，Bold
│ 工银智涌                            │ ← 12pt，深灰
│                                     │
│ • 接入超200个数据源                 │ ← 10pt
│ • 构建亿维特征体系                  │
│ • 数字员工覆盖67个场景              │
│ • 替代人工处理3.3亿笔业务           │
└─────────────────────────────────────┘
```

### 5.2 案例对比表

**多案例对比时使用表格：**
| 企业 | 大模型 | 应用场景 | 核心成效 |
|------|--------|----------|----------|
| 工行 | 工银智涌 | 信贷审批 | 效率提升X% |

## 六、免责声明页（投研报告必需）

**国金证券/毕马威标准：**

**必含内容：**
1. 免责说明标题
2. 信息准确性声明
3. 责任限制条款
4. 版权声明
5. 投资风险提示（投研报告）

**格式：**
- 小号字体（9-10pt）
- 灰色文字（RGB:128,128,128）
- 居左对齐
- 大量留白

**示例内容：**
```
免责声明：
本报告基于公开资料整理分析，所载数据来源于XXX等公开渠道。报告中的市场规模
估算、趋势预测等内容基于现有资料推断，仅供参考。部分数据可能存在滞后或不
完整的情况，使用时请结合实际情况判断。

本报告版权归编制单位所有，未经授权不得转载。
```

## 七、投研PPT特殊要求

从国金证券研报提炼的特殊标准：

### 7.1 避免的"问题"

| 问题 | 正确做法 |
|------|----------|
| 难以使用自定义模板 | 必须支持企业VI模板定制 |
| 排版浮夸 | 重内容轻形式，避免花哨设计 |
| 无法插入原图 | 必须能获取并插入报告原始图表 |
| 内容幻觉 | 所有数据必须标注来源，可溯源 |

### 7.2 必须做到的"专业"

- ✅ 清晰的结论表达
- ✅ 准确的数据引用
- ✅ 专业的图表呈现
- ✅ 统一的视觉风格
- ✅ 严谨的免责声明
- ✅ 支持自定义模板

## 八、自检Checklist

### 视觉设计 ✓
- [ ] 配色符合专业标准（深蓝+科技蓝+橙色）

- [ ] 目录层级清晰（6章左右）

- [ ] 结论先行，数据支撑
- [ ] 术语使用规范统一
