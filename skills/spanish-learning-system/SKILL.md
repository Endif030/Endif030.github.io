# Spanish Learning System

执行“文档主线 + 语音训练并行”学习流程，默认以飞书文档承载内容、飞书聊天承载互动练习。

## 核心工作流

1. 生成/更新《西班牙语A1学习主文档》
2. 按周输出学习目标与 Day1-Day5 任务
3. 每日执行：文本学习 + 语音练习
4. 每周执行：周测 + 复盘 + 下周微调

## 交互协议（固定口令）

- 开始今天西语课程（Day X）
- 进入语音练习（Day X）
- 更新学习文档
- 本周复盘

## 输出规范

- 先给用户可直接执行的当日任务
- 给出语音练习句单（8-12句）
- 给出纠音反馈结构：转写结果 / 内容偏差 / 发音问题 / 示范读音
- 将周计划与复盘回写到飞书文档

## 语音训练规范

- 默认使用“语音转写 + 发音纠错”流程
- 优先指出重音、连读、易错音（如 rr, j, ll）
- 每次最多 3 个纠音重点，避免认知负担

## 周复盘规范

- 仅保留对学习有价值信息：
  - 本周完成度
  - 高频错误清单
  - 下周重点
- 不写过程噪音说明
