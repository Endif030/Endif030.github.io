# 西班牙语学习工作流（文档+语音整合）

## 目标
12周从0基础到A1入门可用水平。

## 交互形式
- 飞书聊天：每日互动
- 飞书文档：周计划、作业、复盘
- 语音训练：语音转写 + 发音纠错 + 示范读音

## 固定指令
1. 开始今天西语课程（Day X）
2. 进入语音练习（Day X）
3. 更新学习文档
4. 本周复盘

## 每周节奏
- 周一：发布本周内容
- 周二~周五：学习+语音
- 周六：周测
- 周日：复盘与调优

## 质量控制
- 每次语音反馈最多3个纠音点
- 每周输出错误清单与下周重点
- 文档只保留学习有效信息

## 专用 Subagent 约定
后续所有学习任务优先由 `spanish-learning-agent` 会话承载（persistent session）。
