# 资料来源管理规范

## 如何区分和管理不同来源的研究资料

---

## 一、资料来源分类

### 1.1 一手资料（私有/内部）

**定义**：直接获取的、未公开发布的资料

**类型**：
- 专家访谈记录
- 企业内部数据
- 实地调研笔记
- 会议纪要和路演材料
- 未公开的行业交流

**标注格式**：
```
私有资料：{受访者/机构}，{时间}
例：私有资料：科大讯飞专家访谈，2023年11月
例：私有资料：iFlytek内部路演材料，2024年1月
```

### 1.2 二手资料（公开）

**定义**：已公开发布的研究报告、新闻、数据

**类型**：
- 咨询机构报告（毕马威、艾瑞、灼识等）
- 券商研报（国金、中信、中金等）
- 行业媒体文章
- 公司财报和公告
- 政府统计数据

**标注格式**：
```
公开资料：{报告名称}，{发布机构}，{发布时间}
例：公开资料：《2024中国金融科技企业首席洞察报告》，毕马威，2024年
例：公开资料：《大模型与AIGC蓝皮书》，灼识咨询，2023年
```

### 1.3 公开新闻/资讯

**定义**：媒体报道、新闻稿、公开演讲

**标注格式**：
```
公开资讯：{文章标题}，{媒体}，{发布时间}
例：公开资讯：《银行业AI大模型从入局到求变》，36氪，2024年11月
```

## 二、来源可信度评级

| 评级 | 来源类型 | 可信度 | 使用建议 |
|------|----------|--------|----------|
| ⭐⭐⭐⭐⭐ | 权威机构报告（毕马威、艾瑞、灼识） | 极高 | 可作为核心数据引用 |
| ⭐⭐⭐⭐⭐ | 券商研报（头部券商） | 极高 | 投研级数据标准 |
| ⭐⭐⭐⭐ | 上市公司财报 | 高 | 财务数据首选 |
| ⭐⭐⭐⭐ | 知名企业官方发布 | 高 | 案例和数据可靠 |
| ⭐⭐⭐ | 行业媒体深度报道 | 中 | 需交叉验证 |
| ⭐⭐⭐ | 专家访谈（私有） | 中 | 观点类信息，需多方印证 |
| ⭐⭐ | 一般媒体报道 | 中低 | 需谨慎使用 |
| ⭐ | 社交媒体/论坛 | 低 | 仅作趋势参考 |

## 四、引用规范

### 4.1 PPT中的引用

**图表底部标注**：
```
数据来源：毕马威2024中国金融科技企业首席洞察报告
私有资料：科大讯飞专家访谈，2023年11月
```

**正文中的引用**：
```
根据毕马威调研，91%的受访企业看好大模型金融应用前景[1]。
结合专家访谈，私有化部署是金融行业的首选模式[2]。

[1] 毕马威2024中国金融科技企业首席洞察报告
[2] 私有资料：科大讯飞专家访谈，2023年11月
```

### 4.2 报告中的引用

**脚注格式**：
```
金融大模型市场2024年规模预计达26.46亿元¹。

¹ 头豹研究院《金融大模型：重塑金融生态》，2024年
```

**参考文献格式**：
```
## 参考文献

[1] 毕马威. 2024中国金融科技企业首席洞察报告[R]. 2024.
[2] 灼识咨询. 大模型与AIGC蓝皮书[R]. 2023.
[3] 科大讯飞. 专家访谈[Z]. 2023-11-15. (私有资料)
```

## 五、数据缺口标注

### 5.1 标注格式

使用 ⚠️ 符号在表格或正文中标注缺失数据：

| 指标 | 中国市场 | 美国市场 |
|------|----------|----------|
| 市场规模 | ⚠️ 数据缺失 | $3.1B |
| 健身房数量 | 811家 | ~500家（估算） |

### 5.2 缺口说明

在报告附录中详细说明：

```
## 数据缺口说明

| 缺失数据 | 重要程度 | 缺失原因 | 建议获取渠道 |
|----------|----------|----------|--------------|
| 中国攀岩市场规模(亿元) | ⭐⭐⭐⭐⭐ | 权威机构未发布 | 中国登山协会、艾瑞咨询 |
| 美国攀岩人口细分数据 | ⭐⭐⭐⭐ | 统计口径不一致 | Climbing Business Journal |
```

## 六、使用建议

### 6.1 优先级原则

1. **高可信度优先**：优先使用⭐⭐⭐⭐⭐级来源
2. **交叉验证**：关键数据需2个以上来源验证
3. **时效性优先**：使用最新发布的资料
4. **标注清晰**：私有/公有资料严格区分

### 6.2 避免的误区

- ❌ 不标注来源
- ❌ 混淆私有和公有资料
- ❌ 使用过时的数据（超过2年）
- ❌ 单一来源的关键结论
- ❌ 未经验证的估算数据
