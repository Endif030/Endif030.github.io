# 变更日志 (Changelog)

所有显著的变更都将记录在此文件中。

格式基于 [Keep a Changelog](https://keepachangelog.com/zh-CN/1.0.0/)。

## [2.0.0] - 2026-03-26

### 重构
- 基于 Superpowers 方法论重构 SKILL.md
- 引入结构化工作流（Phase 1-8）
- 每个阶段定义明确的 Definition of Done

### 新增
- `scripts/health_check.py` - 健康检查脚本
  - 检查数据源连通性（arXiv、Semantic Scholar）
  - 检查 PDF 文件完整性
  - 检查知识卡片状态
  - 检查定时任务配置
  - 检查日志文件状态
  - 周收尾完整检查
  
- `scripts/quality_check.py` - 质量检查脚本
  - 验证注释稿格式规范（6 项检查点）
  - 检查封面信息完整性
  - 检查段落格式（粗体标注、分割线）
  - 检查术语解释数量
  - 检查跨学科关联分析

- `MAINTENANCE.md` - 维护者文档
  - 每日检查清单
  - 定时任务管理指南
  - 故障排查详细步骤
  - 数据备份/恢复流程
  - 紧急恢复方案

### 修复
- `cron_jobs/flashcard_push.sh` - 修复消息发送逻辑
  - 原代码使用管道传递消息，可能导致内容为空
  - 改为直接读取文件内容传递给 `--message` 参数

### 改进
- SKILL.md 新增"快速开始"章节
- SKILL.md 新增"故障排查"章节
- 所有任务清单化，支持勾选追踪
- 明确定时任务使用系统 crontab（稳定可靠）
- 添加版本历史和变更日志

### 文档
- 更新注释稿格式规范示例
- 添加维护者检查清单
- 添加常见问题快速修复命令
