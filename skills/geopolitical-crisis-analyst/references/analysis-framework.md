## 二、矛盾分析矩阵

### 2.1 四层矛盾模型

```
┌──────────────────────────────────────────────────────────────┐
│                      矛盾分析金字塔                           │
├──────────────────────────────────────────────────────────────┤
│  Layer 4: 表象矛盾（公开宣称的理由）                           │
│  例："伊朗核威胁"、"主权权利"                                 │
├──────────────────────────────────────────────────────────────┤
│  Layer 3: 触发因素（直接导火索）                               │
│  例：谈判破裂、军事挑衅、暗杀事件                              │
├──────────────────────────────────────────────────────────────┤
│  Layer 2: 结构性矛盾（长期存在的根本分歧）                      │
│  例：地区主导权、意识形态对立、安全困境                        │
├──────────────────────────────────────────────────────────────┤
│  Layer 1: 深层根源（历史、文化、地缘政治）                     │
│  例：殖民遗产、民族矛盾、资源争夺                              │
└──────────────────────────────────────────────────────────────┘
```

### 2.2 矛盾分析清单

#### 结构性矛盾分析
| 问题 | 分析内容 |
|------|----------|
| 矛盾双方是谁？ | 明确冲突主体 |
| 表面争议是什么？ | 公开宣称的冲突点 |
| 实际利益冲突是什么？ | 真实的利益分歧 |
| 矛盾是否可以调和？ | 有无妥协空间 |
| 历史先例？ | 类似矛盾的解决/升级案例 |

#### 触发因素分析
| 问题 | 分析内容 |
|------|----------|
| 触发事件是什么？ | 导致冲突升级的导火索 |
| 触发时机为何是现在？ | 为什么选择此时升级 |
| 触发是否有意为之？ | 故意挑衅还是意外升级 |
| 触发后的连锁反应？ | 升级链条如何展开 |

#### 各方诉求分析
| 参与方 | 公开诉求 | 真实诉求 | 底线 | 弹性空间 |
|--------|----------|----------|------|----------|
| A方 | | | | |
| B方 | | | | |
| C方 | | | | |

## 四、演变预测方法

### 4.1 情景规划法

```
┌─────────────────────────────────────────────────────────────┐
│                       情景规划模型                            │
├──────────────┬──────────────┬──────────────┬────────────────┤
│   关键变量    │    情景A     │    情景B     │     情景C      │
├──────────────┼──────────────┼──────────────┼────────────────┤
│ 变量1: XX    │ 状态A1       │ 状态B1       │ 状态C1         │
│ 变量2: YY    │ 状态A2       │ 状态B2       │ 状态C2         │
│ 变量3: ZZ    │ 状态A3       │ 状态B3       │ 状态C3         │
├──────────────┼──────────────┼──────────────┼────────────────┤
│  概率评估    │   40%        │   35%        │   25%          │
└──────────────┴──────────────┴──────────────┴────────────────┘
```

### 4.2 关键变量识别

**识别标准**：
- 对局势走向有决定性影响
- 可观察、可监测
- 可能发生显著变化

**常见关键变量**：
1. 军事变量：制空权、弹药库存、伤亡率
2. 政治变量：政权稳定性、民众支持度
3. 经济变量：油价、制裁效果
4. 外交变量：盟友立场、国际干预

### 4.3 时间维度分析

#### 短期（1-2周）：军事逻辑主导
- 战术层面的攻防
- 即时反应和报复
- 媒体叙事争夺

#### 中期（1-3月）：成本-收益计算
- 经济承受力考验
- 国际压力累积
- 内部政治变化

#### 长期（3月+）：结构性因素
- 地缘政治格局重塑
- 力量平衡变化
- 新秩序建立

## 六、信息源评估

### 6.1 可信度评级

| 评级 | 来源类型 | 示例 | 使用建议 |
|------|----------|------|----------|
| ⭐⭐⭐⭐⭐ | 官方声明 | 政府、军方、外交部门 | 可作为事实引用 |
| ⭐⭐⭐⭐⭐ | 权威媒体 | Reuters, AP, BBC | 高可信度 |
| ⭐⭐⭐⭐ | 知名智库 | IISS, CSIS, 布鲁金斯 | 专业分析 |
| ⭐⭐⭐ | 专家分析 | 学者、前官员 | 需交叉验证 |
| ⭐⭐ | 一般媒体 | 地方媒体、专业媒体 | 需谨慎使用 |
| ⭐ | 社交媒体 | Twitter, Telegram | 仅作参考 |

### 6.2 信息交叉验证

**验证方法**：
1. 三角验证：三个独立来源确认
2. 反向验证：反驳性报道检查
3. 时效验证：最新信息优先
4. 利益验证：考虑信息源立场
